# Store Pricing Hub: Design Deliverables

A single-page web application for a retail chain of about 3,000 stores in several countries. It is used to:

- **Upload and save** store pricing feeds (CSV files with Store ID, SKU, Product Name, Price, Date).
- **Search** pricing records using several criteria, and **edit and save** any record.
